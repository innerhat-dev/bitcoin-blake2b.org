What is Bitcoin?

Bitcoin is money that uses peer-to-peer technology to operate with no central authority or banks. Transactions and the issuing of bitcoins are carried out collectively by the network. Its design is public. Nobody owns or controls Bitcoin, and everyone can take part.

Your coins, keys, and addresses are unchanged. Run a node if you want to participate and verify for yourself.

Why this hardfork exists

Bitcoin is an innovative payment network and a new kind of money, and running a full node is how anyone can participate and verify for themselves. BIP-110, in alignment with the vast majority of node policy, attempted to reject use of the network for arbitrary data storage while leaving ordinary payments alone. That was a softfork: a tighter rule that old software can still follow, and it is not this hardfork. A hardfork is a break away from abuse of the Bitcoin network, and software that does not upgrade will not accept the new blocks.

Large mining firms refused those limits and kept producing blocks that used transactions most nodes would not relay as a matter of policy. Anyone can still verify that chain, but following it means accepting use of the network for arbitrary data storage, which every node operator on that chain must store at their own expense and most importantly, risk.

On August 8, 2026, nodes enforcing BIP-110 stopped accepting blocks that did not support it, while most SHA256d mining power kept producing those blocks, so the money-only rules could not activate. Proof of work later changed from SHA256d to BLAKE2b, a different algorithm, so today's SHA256d miners cannot add blocks here. The first BLAKE2b block is 961640 (30 August 2026). Temporary limits on arbitrary data storage began at that height as a flag day, together with BLAKE2b, and last until 1 September 2027, 00:00 UTC (when nodes vote to continue enforcement), using the previous block's median time past; the BLAKE2b algorithm remains after those limits end.
